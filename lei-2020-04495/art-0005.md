Art. 5º As lixeiras deverão ser distribuídas pela escola da seguinte forma:
I - na cozinha, uma marrom para resíduos não recicláveis, uma amarela para resíduos recicláveis e uma cinza para resíduos orgânicos;
II - no refeitório, uma marrom para resíduos não recicláveis, uma amarela para resíduos recicláveis e uma cinza para resíduos orgânicos;
III - nos pátios, uma amarela para resíduos recicláveis e uma marrom para resíduos não recicláveis;
IV - nos banheiros, uma marrom para resíduos não recicláveis.
